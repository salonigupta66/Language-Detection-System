# Language Detection System

## Overview
The Language Detection System is a Machine Learning project that automatically identifies the language of a given text using Natural Language Processing (NLP) techniques. It enables fast and accurate language classification for multilingual text.

## Features
- Text Preprocessing
- Language Classification
- TF-IDF Feature Extraction
- Machine Learning Prediction
- Model Evaluation

## Tech Stack
**Python • Pandas • NumPy • Scikit-learn • NLTK • TF-IDF • Jupyter Notebook**

## Model
- Naive Bayes Classifier
- Evaluated using Accuracy, Precision, Recall, and F1-Score.
